# Package notes

Checked against Packagist and the installed lockfile. Do not patch `vendor/`.

| Package | Status |
|---|---|
| `imrandevbd/laravel-ai-hub` 1.7.3 | Installed. `App\Support\Integrations\AiClient` calls it. Tests use `AIHub::fake()`. The bundled `AiHubDashboardWidget` cannot boot on Filament 4.16: it redeclares `$pollingInterval` as static while the parent property is non-static. The widget is not registered. AI Hub settings stay at `/ai-hub`. Calls are skipped when no provider API key is set, so seeding does not wait on a 180s timeout. |
| `imrandevbd/laravel-ai-catalog` | Installed. Migrations run. Public catalogue pages are the mill's own style pages (JSON-LD, `llms.txt`, DPP JSON on the style). Listing generation from the package UI is available; styles are not auto-mapped as catalog products. |
| `imrandevbd/laravel-ai-ocr` | Installed. Not wired to a tech-pack upload action yet. Manual entry remains the source of truth. |
| `imrandevbd/laravel-attendance-hub` | Installed with the virtual driver. Attendance tables migrate. Payroll still uses present-day and piece-rate inputs; device punches are not the payroll source yet. |
| `imrandevbd/laravel-filament-master` | Installed but `dont-discover`. It still imports `Filament\Commands\Concerns\CanManipulateFiles` (the trait lives under `Filament\Support`) and the Filament v3 form API. Discovering it fatals the app. Master screens are hand-built Filament v4 resources. |
| `imrandevbd/laravel-blueprint-studio` | Not installable. Packagist 1.2.0 dist 404, and the git history the lock points at is gone. Models and migrations are generated by `scripts/generate-domain.php`. |
| `imrandevbd/laravel-universal-slug` | Used by `App\Support\Integrations\Slugger`. |
| `imrandevbd/laravel-unicode-pdf` | Used by `App\Support\Integrations\PdfPrinter` for document print. HTML is the fallback if the PDF engine throws. |
| `imrandevbd/laravel-webshell` | Installed. Gate `webshell.access` is true only for a user who sees all branches and only when the `webshell` module is enabled. The module is seeded **off**. |
| `imrandevbd/adhikar` | Not published. Roles are `spatie/laravel-permission` with a super-admin `Gate::before`. |
| `imrandevbd/tarikh` | Used as `Tarikh\Tarikh` for Asia/Dhaka dates and the July financial year. Its composer extra points at `Tarikh\Laravel\TarikhServiceProvider`, which does not exist, so the package is `dont-discover`. There is no Bangla calendar API; Bangla dates use `IntlDateFormatter` (`bn_BD`) with a digit fallback. |
| `imrandevbd/drutogoti` | Installed. Config and tables are published. It is why Laravel 13 was not selected. |
| `imrandevbd/laravel-admin-panel` | Not used. Filament is the admin. Buyer and supplier portals are Blade. |

Foreign keys are created on MySQL and MariaDB. They are skipped on SQLite because each added key rebuilds the table, which made migrate unusable on a slow disk and would make the test suite rebuild the schema hundreds of times.
